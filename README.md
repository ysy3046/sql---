# Amazon 데이터셋 기반 추천 시스템 설계

Amazon 상품 및 평가 데이터를 활용하여 서로 다른 목적을 가진 5가지 규칙 기반 추천 시스템을 SQL로 구현한 프로젝트입니다.

평균 평점, 평가 수, 가격, 할인율, 대표 후기, 리뷰 작성자 및 카테고리 정보를 활용했습니다.

> 이 데이터에는 실제 구매량과 구매·조회 시점이 없으므로, 결과는 구매 예측이 아닌 상품 탐색을 위한 추천 후보로 해석했습니다.

## 추천 시스템 구성

| 번호 | 추천 시스템 | 핵심 로직 |
|---|---|---|
| 1 | 믿고 사는 베스트셀러 | 평균 평점과 로그 변환한 평가 수를 결합 |
| 2 | 할인율 일치 여부를 확인한 고평가 상품 | 표시 할인율과 직접 계산한 할인율 비교 |
| 3 | 대표 후기의 위험 신호가 적은 상품 | 후기에서 네 가지 부정 신호 유형 탐색 |
| 4 | 공통 리뷰어 기반 연관 상품 후보 | 동일 리뷰어가 등장한 상품 쌍 연결 |
| 5 | 카테고리별 균형 추천 | 대분류별 신뢰도 점수 상위 상품 추출 |

## 주요 결과

### 1. 믿고 사는 베스트셀러

평균 평점 4.0 이상, 평가 수 1,000개 이상인 상품을 대상으로 다음 점수를 계산했습니다.

`베스트셀러 점수 = 평균 평점 × LN(평가 수 + 1)`

![믿고 사는 베스트셀러 결과](images/result_01.png)

### 2. 할인율 일치 여부를 확인한 고평가 상품

정가와 할인가를 이용해 할인율을 다시 계산하고, 표시 할인율과의 차이가 2%p 이하인 고평가 상품을 추출했습니다.

결과 검토 과정에서 동일한 상품명이 서로 다른 상품 ID로 반복되는 중복 문제가 발견되었습니다. 이후 상품명 기준의 추가 중복 제거가 필요합니다.

![할인율 일치 여부 확인 결과](images/result_02.png)

### 3. 대표 후기의 위험 신호가 적은 상품

대표 후기에서 고장, 반품, 강한 불만 및 품질 문제와 관련된 표현을 탐색했습니다. 추천된 상위 10개 상품에서는 설정한 네 가지 부정 신호가 모두 발견되지 않았습니다.

![대표 후기 위험 신호 탐색 결과](images/result_03.png)

### 4. 공통 리뷰어 기반 연관 상품 후보

두 상품에 공통으로 리뷰를 남긴 사용자 수를 계산했습니다. 상위 결과에서는 동일 브랜드의 유사 모델이나 색상·길이·규격이 다른 옵션 상품이 주로 연결되었습니다.

![공통 리뷰어 기반 연관 상품 결과](images/result_04.png)

### 5. 카테고리별 균형 추천

전체 상품을 한 번에 순위화하지 않고 대분류별로 추천 점수를 계산하여, 각 카테고리에서 상위 상품을 최대 2개씩 추출했습니다.

![카테고리별 균형 추천 결과](images/result_05.png)

## 주요 한계

- 실제 판매량, 구매 여부, 조회 기록 및 이용 시점이 제공되지 않습니다.
- 개별 사용자가 부여한 평점이 아니라 상품의 전체 평균 평점만 확인할 수 있습니다.
- 후기 내용은 전체 후기가 아닌 데이터에 포함된 일부 대표 후기입니다.
- 동일하거나 매우 유사한 상품이 서로 다른 상품 ID로 저장된 사례가 있습니다.
- 공통 리뷰어 관계를 동시 구매나 긍정적인 선호로 해석할 수 없습니다.

## 향후 개선 방향

상품명 기준의 추가 중복 제거와 함께 실제 구매 이력, 개별 평점, 클릭 및 조회 기록이 추가된다면 사용자별 선호를 반영한 개인화 추천으로 확장할 수 있습니다.
